## Notes

1. **ARGO2023:** Datasets A–G are in the `thesis_test` folder of the ARGO GitHub repository. Datasets A–E were simulated using [ProbeRequestGenerator](https://github.com/riccardo-rusca/ProbeRequestGenerator) (described in [Privacy-Aware Crowd Monitoring and WiFi Traffic Emulation for Effective Crisis Management](https://ieeexplore.ieee.org/document/10286944)). Datasets F–G contain real device captures: F is based on the `Cagliari2021` dataset and G was custom made by the researchers. The `Captures0210` folder contains further datasets with ground truth information; its counts combine the Corridor and Room captures.
2. **WiFiAnon2025:** The dataset consists of CSV files (one row per frame) and contains no Probe Requests.
